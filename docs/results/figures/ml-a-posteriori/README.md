# ml-a-posteriori figures

ROM runs with learned closures for Re120 Ca0.01 β45, 10 Hz, from t = 1800 (write-up: `../../ml-a-posteriori.md`). Scripts: `scripts/figures/ml-a-posteriori/` with `--set <date>`. The `.mp4` animations are not in git; regenerate them with `anim01_h_full_domain.py`.

| Folder | Contents |
|---|---|
| `comparisons_2026-11-05/` | Learned ΔM_x + ΔT_w (one sum model, or separate models) against Lavalle alone and the oracle, t = 1800–1900. |
| `comparisons_2026-11-12/` | The same closures plus the ΔP_x v2 MLPs (G_s0p5, H_s0p5), against Lavalle, the oracle and the sum model without ΔP_x, t = 1800–1900. |
